Проект содержит третье задание части автоматизации для яндекс практикум
Задание оринтированно на тестирование UI учебного веб-приложения
В проекте содержатся следующие папки и файлы:
    1) allure_results - содержит файлы отчета о тестировании, просмотреть отчет можно командой: allure serve allure_results
    2) locators содержит файлы:
        a) base_locators - содержит локаторы элементов общих для всех страницы
        b) login_page_locators - содержит локаторы страницы входа в профиль
        c) main_page_locators - содержит локаторы основной страницы приложения (конструктора)
        d) order_feed_locators - содержит локаторы страницы Лента заказов
        e) personal_account_locators - содержит локаторы страницы Личный кабинет
    3) pages содержит файлы:
        a) base_page - содержит базовые функции взаимодействия с объектами страницы и общие для всех страниц функции
        b) login_page - содержит функции для взаимодействия с элементами страницы входа в профиль
        c) main_page - содержит функции для взаимодействия с элементами главной страницы (конструктором)
        d) order_feed_page - содержит функции для взаимодействия с элементами страницы Лента заказов
        e) personal_account_page - содержит функции для взаимодействия с элементами страницы Личный кабинет
    4) tests содержит файлы:
        a) test_login_page - содержит тесты перехода по кнопкам Конструктор и Лента заказов
        b) test_main_page - содержит тесты перехода по кнопке Лента заказов, проверки вывода окна ингредиента при клике по ингредиенту, проверки работоспособности кнопки Крестик в окне информации об ингредиенте, проверки изменения счетчика ингредиентов при добавлении их в конструктор
        c) test_order_feed_page - содержит тесты перехода по кнопке Конструктор, проверку счетчика выполненных заказов за всё время, проверку счетчика выполненных заказов за сегодня, проверка добавления номера заказа в раздел В работе
        d) test_personal_account_page - содержит тесты перехода по кнопкам Конструктор и Лента заказов
    5) conftest - содежит фикстуры для тестов
    6) constants - содержит ссылки используемые тестами и их функциями
    7) data - содержит тестовые данные
    8) requirements - содержит весь список библиотек установленных у разработчика тестов, установить библиотеки можно командой: pip install -r requirements.txt
